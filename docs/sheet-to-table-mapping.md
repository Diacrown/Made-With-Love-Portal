# Google Sheet "DB Schema" -> Supabase mapping

| Sheet tab | Column | Table.column | Transform |
|---|---|---|---|
| Company | CompanyCode / CompanyName | `companies.code` / `.name` | upsert key = code |
| Company | Address (`a \| b \| c`) | `companies.address_lines text[]` | split on `\|` |
| Office | OfficeCode / Name / City / Country | `offices.code/name/city/country` | upsert key = code |
| Office | CompanyID | `offices.company_id` | sheet ID -> CompanyCode -> DB id |
| Office | BackOfficeID | `offices.back_office_id` | sheet OfficeID -> OfficeCode -> DB id (2nd pass, self-FK) |
| Office | Phone | `offices.phone_raw` | kept raw for now |
| Office | Whatsapp | `offices.whatsapp` | digits only (E.164 without `+`) |
| Office | Tax_Caption | `offices.tax_caption` + `offices.tax_rate` | percent parsed from text |
| Office | Currency | `offices.currency_code` -> `currencies` | |
| Office | FXR | `exchange_rates.rate_per_usd` | dated row per currency, base USD |
| Office | Logo | `offices.logo_url` | later: Supabase Storage |
| Office | JobCounterID / InvoiceCounterID | `offices.job_counter_id` / `invoice_counter_id` | sheet CounterID -> prefix -> DB id |
| Counter | Type / CounterPrefix | `counters.type` / `.prefix` | invoice counters = yearly reset, job = never |
| Counter | LastValue | `counter_values.last_value` | seeded once, never overwritten on re-sync |
| Customer | OfficeID / EZJAcNum / Alias | `customers.office_id / ezj_ac_num / alias` | legacy EZJEMS key kept |
| CustomerPvt | Name, addresses, Email, Whatsapp, Currency, TaxPerc | `customer_private.*` | PII table, front office only |
| CustomerPvt | PaymentTerms / ShipVia | `payment_terms` / `ship_via` lookups | distinct values upserted |
| CustomerPvt | Contacts | `customer_contacts` | single free-text cell -> one contact row to clean up |
| JobHeader | all columns | `jobs` | structure only; no data yet. `job_no` generated by trigger |

## Access matrix (enforced by RLS)

| Table | admin | front office (own office) | back office (serving) |
|---|---|---|---|
| companies, offices, lookups | read/write | read | read |
| customers (alias, account no.) | all | read/write | read |
| customer_private, customer_contacts | all | read/write | none |
| jobs | all | read/create/update (front office) | read/update (back office) |
| counters | none (via function only) | none | none |
